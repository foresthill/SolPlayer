# ショート動画 設計書（柱2・聴き比べ3本）

縦型 1080×1920 / 15〜30秒 / YouTube Shorts・TikTok・X共通素材。
**著作権の鉄則**: YouTube上の他人の曲を変換して流さない。音源はすべて自作
（またはSolPlayerで変換した自作曲）。デモ画面も**自分のYouTubeチャンネルに
上げた自作曲動画**を使えば、権利クリアかつ本物の製品デモになる。

## 事前に用意するもの

1. **自作デモ音源**: ピアノ系の8〜10秒フレーズ（440Hz版と432Hz版）。
   Claude側でWAV生成可能（440Hz基準で合成→SoundTouchで432Hz版を作ると
   「本物の変換結果」になる）
2. **自分のYouTubeチャンネルに自作曲動画を1本アップ**（デモ撮影用。
   概要欄に「SolPlayer Tuneのデモ用」と書いておく）
3. iPhoneの画面収録（設定→コントロールセンターに追加）

## 動画1「違い、わかる？」（本命・20秒）

ターゲット: 432Hzに興味がある層＋音感に自信がある層（参加型フック）

| 秒 | 画 | 音 | テロップ |
| --- | --- | --- | --- |
| 0-2 | 黒背景に大きな文字だけ | 無音→ピアノ開始 | 「440Hzと432Hz、違いわかる？」 |
| 2-6 | パネルUIのアップ（440Hz選択状態） | フレーズA（440Hz版） | 「ふつうのチューニング 440Hz」 |
| 6-8 | 指が432Hzチップをタップする実写 | （タップ音） | 「↓ ワンタップで」 |
| 8-12 | ボタンがグラデに変わるアップ | 同じフレーズA（432Hz版） | 「432Hz」 |
| 12-18 | 2画面分割で波形イメージ＋UI | A/Bを2秒ずつ交互 | 「440 → 432 → 440 → 432」 |
| 18-20 | ロゴ＋3プラットフォーム | ピアノ余韻 | 「無料拡張 SolPlayer Tune🔍」 |

- コメント誘導: 概要/固定コメントに「どっちが好きだった？」
- 絶対に「効果がある」と言わない（「あなたの耳で確かめて」の誠実路線）

## 動画2「iPhoneでYouTubeを432Hzにする方法」（ハウツー・30秒）

ターゲット: 「iphone youtube 432hz」検索層。検索流入が長く効くタイプ

| 秒 | 画 | テロップ |
| --- | --- | --- |
| 0-3 | YouTube再生画面（自作曲動画） | 「iPhoneでYouTubeを432Hzで聴く方法」 |
| 3-8 | App Storeで「SolPlayer Tune」DL | 「① App Storeで入手（無料）」 |
| 8-15 | 設定→アプリ→Safari→機能拡張→ON＋許可 | 「② Safariの機能拡張をON」 |
| 15-23 | SafariでYouTube→♪ボタン→432Hzタップ | 「③ ♪ボタンをタップするだけ」 |
| 23-28 | 音が変わる瞬間（自作曲で） | 「保存・収集は一切なし」 |
| 28-30 | ロゴ＋「Android/PCも無料」 | 「検索: SolPlayer Tune」 |

- 音声は③以降だけ生かす（自作曲なので安全）。前半はBGMなしor自作音源

| 秒 | 画 | テロップ |
| --- | --- | --- |
