YouTubeで音楽を聴くとき、「432Hzで聴きたい」と思ったことはありませんか。

432Hzは、現代の標準チューニング（A=440Hz）より少しだけ低いピッチです。科学的に効果が証明されているわけではありませんが、「角が取れて柔らかく聴こえる」「リラックスできる気がする」と感じる人が世界中にいて、432Hz版に変換された音源を探して聴いている人も多くいます。

ただ、従来のやり方には不満がありました。

- 「〇〇 432Hz」で変換済み動画を探す → **聴きたい曲があるとは限らない**。音質もまちまち
- 動画をダウンロードして変換ソフトにかける → 手間がかかるうえ、**YouTubeの規約違反**
- 変換アプリにURLを貼る系のサービス → 仕組み的にグレーなものが多い

そこで、**いま見ているYouTubeの音を、その場でリアルタイムに432Hzへ変換するブラウザ拡張**を作りました。無料です。

## SolPlayer Tune でできること

- YouTubeの視聴ページに「♪ 440Hz」ボタンが現れ、**ワンタップで432Hzに変換**
- プリセットは 440（標準）/ 432 / 437 / 444Hz。**444Hz調律ではド（C5）がちょうど528Hz**になるので、いわゆるソルフェジオ周波数で聴きたい人は444Hzをどうぞ
- 小数第10位まで指定できる**カスタム周波数**（200〜999Hz）と、**マイプリセット保存**
- 440Hzに戻せば完全に無変換（元の音そのまま）

そして大事なこと:

- **ダウンロード・録音・保存は一切しません**。再生中の音をその場で処理するだけです（規約に配慮した設計です）
- **データ収集もゼロ**。アカウント不要、トラッキングなし、設定は端末の中だけ

## 使い方

### PC（Chrome / Edge）

1. Chrome Web Storeで「SolPlayer Tune」をインストール
   → ※リンク差し替え
2. YouTubeを開くと動画の下に「♪ 440Hz」ボタンが出ます
3. クリックして432Hzを選ぶだけ

### Android（Firefox）

1. Android版Firefoxのアドオンから「SolPlayer Tune」を追加
   → ※リンク差し替え
2. youtube.com へのアクセスを許可
3. あとはPCと同じ。**スマホでYouTubeを432Hz**、できます

### iPhone / iPad（Safari）

1. App Storeから「SolPlayer Tune」をインストール
   → https://apps.apple.com/jp/app/id6800237084
2. 設定 → アプリ → Safari → 機能拡張 で SolPlayer Tune をオン、youtube.com を「許可」
3. SafariでYouTubeを開いて♪ボタンをタップ

※iPhoneだけは技術的な制約（WebKitの仕様）で、レコードの回転数を変えるのと同じ「再生速度方式」で変換します。432Hzでは再生が約1.8%ゆっくりになります（3分の曲で約3秒）。映像も一緒にゆっくりになるので音ズレはありません。このあたりを正直に書いているツールは少ないので、あえて明記しておきます。

## よくある質問

**Q. 音質は劣化しない？**
変換時はリアルタイム処理を通るぶん、原理的には完全無劣化ではありません。ただ普通に音楽を聴く用途で気になるレベルではないはずです。440Hzに戻せば処理を完全にバイパスするので元の音のままです。

**Q. 432Hzって本当に効果あるの？**
科学的なエビデンスがあるとは言いません。「自分の耳で聴き比べて、心地よければそれでいい」というスタンスで作っています。このツールならワンタップで440⇄432を切り替えられるので、ぜひ自分の耳で確かめてください。
