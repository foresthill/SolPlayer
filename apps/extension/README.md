# SolPlayer Tune（Chrome拡張・プロトタイプ）

YouTubeのページに「♪ 440Hz」トグルボタンを注入し、**その場で432Hz/444Hzに変換して聴ける**Chrome拡張。

## 仕組み（タブキャプチャ不要のブレイクスルー）

`createMediaElementSource(video)` でページ内の`<video>`要素の音声出力を
**丸ごとWeb Audioへ付け替え**、SoundTouchでピッチのみ変換して出力する。

- 元音との二重再生が**構造的に起きない**（要素の直接出力自体が無くなるため）
- タブキャプチャ・共有ダイアログ・消音フラグ・タブの行き来がすべて不要
- 映像はそのまま見える（音声の処理遅延 約0.2〜0.3秒ぶんリップシンクがずれる）
- 音声データは保存しない（リアルタイム処理のみ。ダウンロード機能なし）
- 440Hz（変換オフ）時は素通しバイパス（遅延・負荷ゼロ）

## 検証済み（E2E実測）

- 440Hz正弦波の動画 → 変換ON → **出力432.00Hz / 444.01Hz を実測確認**
- バイパス復帰・変換再開・トグルUI注入も確認
- 保護コンテンツ（CORS/DRM）は仕様により無音になる（その場合は440Hzへ戻して使用）

## 使い方（開発版の読み込み）

```bash
cd apps/extension
pnpm build        # dist/ が生成される
```

1. Chromeで `chrome://extensions` を開く
2. 右上「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ `apps/extension/dist` を選択
4. YouTubeを開くと右下に「♪ 440Hz」ボタンが出る。クリックで 440 → 432 → 444 → 440 と切替
